# MBReadyTimer v3.2.0

**FFXI 黒魔道士 MB (マジックバースト) 次詠唱可能・硬直可視化 Windower 4 アドオン**

---

## 🌟 概要
自動キャスト (autocast) による FFXI クライアントのクラッシュ・POL落ちリスクを完全に排除した、**100% 安全・受動型の次魔法着弾・硬直解除ナビゲーションアドオン**です。

FFXI 画面左上の標準キャストタイマー (100% ➔ 0% カウントダウン表示) と完全同調する HUD オーバーレイバーをリアルタイム表示し、ジャ系・古代II・精霊6系などの着弾タイミング、および着弾後のサーバー/アニメーション硬直が明ける瞬間 (例: ジャ系 Cast Timer 残り 36.0% 通過時) を音と光で通知します。

---

## 💡 主な特徴と技術仕様
- **Windower 4 公式規格準拠 (`config`, `texts`, `resources`, `packets`)**
- **画面左上 Cast Timer カウントダウン完全同調**:
  - `100.0% ➔ 80.0%`: 精霊魔法詠唱中 (ジャ系実効詠唱 1.4秒)
  - `80.0%  ➔ 36.0%`: 着弾後・サーバー/アニメーション硬直中 (約 3.08秒)
  - `36.0%  ➔  0.0%`: **★ READY! (硬直完全解除・次魔法即キャスト可能)**
- **次推奨魔法ナビゲーション**: 連携枠の残り秒数に応じた最高火力の魔法を安全に提示。
- **設定自動保存 (`data/settings.xml`)**: FC率 (`fc`), 目標解除% (`lock`), 位置 (`pos`), 効果音 (`sound`) などを永続化。
- **POLクラッシュ 0%**: クライアントフリーズ・メモリ割り込みリスクを排除。

---

## 💻 コマンド一覧 (`//mbr` または `//mbtimer`)

| コマンド | 実行例・機能説明 |
| :--- | :--- |
| `//mbr lock <残り%>` | ジャ系の硬直解除%目標を調整 (例: `//mbr lock 36`) |
| `//mbr fc <FC率>` | ファストキャスト率設定の変更 (例: `//mbr fc 80`) |
| `//mbr pos <x> <y>` | HUD表示位置を変更 (例: `//mbr pos 600 400`) |
| `//mbr sound` | READY効果音の ON / OFF 切り替え |
| `//mbr hud` | 画面HUD表示の ON / OFF 切り替え |
| `//mbr test` | 画面上でカウントダウン動作テストを実行 |

---

## 📦 導入手順
1. `MBReadyTimer_v3.2.0.zip` を解凍します。
2. Windower 4 の `addons/MBReadyTimer/` フォルダへ配置します。
3. ゲーム内で `//lua load MBReadyTimer` を実行します。
